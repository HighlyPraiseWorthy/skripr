# AI search citation check (monthly, manual, free)

Once a month, ask the same 10 questions in 4 AI engines and log whether
skripr.app is cited. Takes about 15 minutes. No APIs, no cost.

Why manual: what real users see in the consumer apps differs from API output,
and ChatGPT and Google AI Mode have no usable API for this anyway.

## How to run it
1. Open each engine **logged out or in a private window** (so your own history
   doesn't bias the answer):
   - ChatGPT: chatgpt.com (search on)
   - Perplexity: perplexity.ai
   - Google AI Mode: google.com, then the "AI Mode" tab
   - Claude: claude.ai (web search on)
2. Paste each question exactly as written below. Don't reword it.
3. For each answer, note:
   - **Cited?** Y if skripr.app is linked or named, otherwise N
   - **Who was cited:** the top 2 or 3 sites or tools named
4. Add a dated section to the log at the bottom of this file. Commit it.

## The 10 questions (keep these fixed so months are comparable)
1. What is the best AI YouTube script writer?
2. What is a good Subscribr alternative?
3. Is there an AI tool that writes a YouTube script based on a video that already went viral?
4. What is the best free YouTube transcript generator?
5. What are the best AI tools for faceless YouTube channels?
6. How do I write a script for a faceless YouTube channel?
7. What is a free YouTube video ideas generator?
8. What is the best ChatGPT alternative for writing YouTube scripts?
9. What is a free YouTube channel name generator?
10. What is a free YouTube title generator?

## What to look for
- The first month is the **baseline**. Expect mostly N. The domain is young.
- When a competitor is cited for a question Skripr has a page for, open the
  cited page and note what it has that ours doesn't: a direct 40 to 60 word
  answer at the top, a comparison table, original data, more mentions across
  the web.
- If Skripr starts getting cited, note which page was linked. That's a signal
  worth more than early Google rankings.
